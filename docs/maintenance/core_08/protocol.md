# Core 0.8. Протокол переноса

Исходная версия — 2d69cbfe0d74d2419dabe818b9b932fbfc53e623. Вопросы переноса и рубрика фиксируются после заморозки реализации, до первого запуска на них. После просмотра результатов настройка на этом наборе запрещена.

Сравниваются выпущенный Core 0.7 с локальным голосом за цель, его BM25, BM25 по полному выражению и условию с проверкой вызовов в обе стороны, BM25 с русскими описаниями без поиска связи и полный вариант. У всех одинаковы снимок, вопрос, лимит шести шагов, проверяющий и инструменты доказательства. Лингвистические описания строятся только до испытания. Отдельно проверяется перенос на новые Git-объекты без готовых описаний.

Каждый положительный вопрос получает точные ориентиры, нужный вид ответа и обязательные доказательства. Для прямой связи требуются обе строки признаков, место вызова с правильным направлением и импорт при переходе между файлами. Для объяснения условий проверяются признаки, условия, ранние выходы и их полярность. На отрицательных примерах учитывается причина удержания. Уточнение на разрешимой задаче считается пропуском. Ссылки проверяются независимо от семантической оценки. Ошибкой публикации считается в том числе ответ со статусом answered при неверном виде ответа или недостающих обязательных фактах.

Сохраняются полные ответы с диапазонами строк, решения по каждому пункту, количество действий, затраты на построение индексов, вызовы моделей, журнал генераций и полное время исследовательского вызова. Загрузка модели и подготовка снимка измеряются отдельно. Локальные пути, данные рабочего дерева и секреты в результаты не включаются. Показатели на небольшом авторском наборе не устанавливают качество на произвольных пользовательских задачах.
