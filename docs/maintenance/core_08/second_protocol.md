# Второе сравнение

Первый перенос и результаты фиксированы в 606b0d1 и d260275. Статическая проверка двух ориентиров принесла выигрыш. Русское описание выражения часто сохраняло только одно слово из развёрнутого пересказа. На 22 задачах добавление описаний не улучшило качество по сравнению с простым структурным поиском.

Вторая гипотеза — при недостатке лексических данных перевести сам вопрос в операцию и несколько независимых групп поисковых слов. Интерпретатор не получает ни каталог, ни имена файлов, ни эталон. Им может служить локальная модель с ограниченным JSON-выходом. Хост выбирает записи, проверяет исходники и решает, публиковать ли результат. Один и тот же лексический признак не может удовлетворить две независимые группы. Для связи между двумя признаками хост запрашивает места вызовов и при необходимости меняет направление поиска. Для направленного вопроса разрешено только запрошенное направление.

Сравниваются Core 0.7 с проверкой и без лексического вето, поиск по синтаксису с двумя ориентирами, замороженный детерминированный Core 0.8, тот же перевод вопроса с простым IDF-поиском по объединению слов, и вариант с обязательными группами. Одинаковый проверяющий, до шести действий и до одной интерпретации вопроса на вариант. Сохраняются фактически полученные ответы модели, их совпадение и затраты. Проверяются новые вопросы на реальном снимке и на ранее не использованном синтетическом коде. Реализация фиксируется до вопросов. Первая выборка остаётся исторической и не служит подтверждением второй гипотезы.
