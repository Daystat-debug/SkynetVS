# Проверка смысловой идентичности объектов

На закреплённом снимке сравниваются 0.16, автономное лексическое ранжирование с учётом подслов, однократное смысловое ранжирование и повторная проверка среди конкурирующих гипотез. Сборщик, распределение шагов, интерпретатор типов и проверка доказательств общие. Сравнение модельных вариантов использует одного локального поставщика и одинаковый первый запрос. Повторный запрос учитывается отдельно. При точном уникальном ориентире действует обычный поиск цитаты. Модель может выбирать только из последовательности выражений, сформированной хостом. Классификация объекта остаётся интерпретацией смысла. Выдержка подтверждает наличие слов в источнике.

До измерения закрепляются оценщик и алгоритм. Затем составляется новая серия по нескольким областям с точными цитатами, пересказами, контрастами свойств и полярности, зависимыми просьбами, отсутствием объекта, неопределённостью и внешними данными. Близкие переформулировки оцениваются парами и не используются для настройки. Исторический F10 оценивается отдельно. Дообучение и расширение словаря не предусмотрены.

Оцениваются попадание объекта в список возможных соответствий, окончательная идентичность по снимку и координатам, принятие чужого объекта, предмет и тип в одной части, содержание и Git-ссылки предъявленных фактов, полный и полезный частичный ответ, ошибочная полнота и отказы. Для косвенной ссылки на предыдущий предмет отдельно оценивается итог привязки; список прямого поиска к ней неприменим. Для отрицательных случаев рубрика отделяет просьбу без подходящего объекта от недоступного требования о правильно указанном объекте. Для контраста нужны правильные ответы на обе задачи. Диагностика с известными объектами подставляет лишь координаты разрешимых упоминаний. Расход измеряется по шагам, вызовам, входным и выходным токенам и задержке. Записываются исходные ответы модели с хешами запросов для автономного воспроизведения и отдельная компактная сводка оценок по вопросам.
