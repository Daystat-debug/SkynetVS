# Протокол оценки Core 0.15

Для одной и той же задачи меняется только доступная интерпретатору информация. Снимок, доступ, бюджет в шесть шагов, сборщик фактов и проверки перед публикацией общие. В свободном режиме хост получает только вопрос. В режиме известных объектов оценщик указывает координаты выражений для разрешимых упоминаний. В режиме известных требований он передаёт виды требуемых сведений в местах предикатов исходного вопроса. Общий предикат помечается один раз. Хост сам определяет его область действия и находит объекты. В режиме известной связи передаются координаты объектов и тип для каждого обязательства. Наличие вызывающих участков, условия, аргументы, эталонные факты, доступность доказательства и ожидаемый статус во всех режимах скрыты от исследователя. Оракулы доступны только оценщику.

В каждой записи отдельно проверяются привязка объекта, точный тип с его необходимыми зависимостями, совпадение обеих оценок, доставка непосредственного доказательства с правильным содержимым и Git-ссылками. Считаются как успешные, так и лишние либо пропущенные обязательства. Запрос нескольких вызывающих мест при действующем ограничении единственного вызывающего участка требует явного пробела. Ссылка на строку сообщения считается вспомогательной. Полный ответ требует правильного статуса, выполнения всех обязательств и отсутствия лишних интерпретаций. Полезный частичный требует доставки всех доступных запрошенных фактов, как минимум одного такого факта и явного пробела для каждого недоступного. Отдельно оценивается правильная причина пробела. Для зачёта контраста обе задачи должны получить точные привязки и правильный содержательный результат, включая обоснованное ограничение.

Этап первого расхождения для доступного факта определяется по выбранному объекту и виду требования, реальному расписанию сборщика, затем по полученным и опубликованным утверждениям. Ошибки решения о полноте считаются также отдельно и могут сочетаться с ошибкой интерпретации. Время измеряется в открытом снимке хоста, включая проверку. Порядок стратегий чередуется. Предыдущие серии служат только диагностикой. После фиксации реализации составляется вторая серия до измерений. Ни одна контрольная серия не используется для подбора параметров.
