# Планирование доказательств. Протокол 0.16

Основная единица оценки — непосредственно запрошенный факт для конкретного выражения в закреплённом Git-снимке. Используем независимые от планировщика рубрики и проверку строк Core 0.15. Полнота требует правильного объекта, смысла, статуса и всех запрошенных фактов. Отдельно считаем частичный ответ с хотя бы одним верным прямым фактом и обозначенным пробелом, неправильную принадлежность факта, ложную полноту и полный отказ.

Сравниваем последовательный 0.15, прежний ближайший предикат, совместное использование уже полученных результатов в порядке запроса, простую стратегию дешёвых целей и выбор набора целей по стоимости общих зависимостей. При известной связи хосту передаются только закреплённые координаты предмета и запрошенный тип. Доступность результата, значения, вызывающие участки и эталонные источники доказательства исследователь получает из кода. Синтетические программы разбираются в отдельном Git-клоне без исполнения. R2/D3 из 0.15 служат диагностикой.

Существующая единица шага сохраняется для интерпретации, каждой отдельной локализации, поиска вызовов, анализа условия и нового связывания аргументов. Повторно используемый результат должен уже возникать внутри ранее выполнявшейся операции. Счётчики реальной работы должны отдельно показать построения AST, поиски вызовов, построения сигнатуры, повторные связывания и вычисления условий. Считаем обращения к кешам, максимальное число зарегистрированных элементов доказательств, предъявленные утверждения, шаги и задержку. При утрате подлинности или свежести действует прежний отказ хоста. Общие пределы — шесть шагов, 96 элементов, 25 секунд.

После фиксации реализации и оценщика закрепляем новую серию до первого замера. Она должна включать независимых и общих владельцев выражений, различные виды фактов, перестановки, недостаточный бюджет, неоднозначность и отрицательный случай связывания. Порядок вариантов чередуется. Для перестановок сравниваем доставленные пары объект–тип. Измерения времени относятся к вызову исследователя с открытым снимком, включая проверки и измерительные счётчики. Серия авторская, без настройки на итоговые результаты.
