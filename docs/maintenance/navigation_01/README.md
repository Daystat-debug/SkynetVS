### Как начать с задачи

Из корня репозитория, PowerShell. Команды выводят подсказки и ничего не запускают в анализируемом проекте. `topic` без ключа показывает десять областей и русские описания.

```powershell
$python = './.venv/Scripts/python.exe'
$nav = 'tools/navigation_lab/nav.py'
$rev = 'bceec9c91ce25f58a603adfb32e109543a384fb4'
& $python -I -S -B $nav --snapshot $rev topic
& $python -I -S -B $nav --snapshot $rev topic reminders
& $python -I -S -B $nav --snapshot $rev quick ReminderService
& $python -I -S -B $nav --snapshot $rev file modules/reminder_repository.py
```

* **«Где менять поведение напоминаний и какую проверку читать?»** `topic reminders` ведёт к сервису, хранилищу и eval. `quick ReminderService` находит определение в `modules/reminder_service.py:83`, импорт хранилища на строке 10 и проверки. Открыть только нужные строки снимка. В примере ниже строки 83–100.
* **«Что зависит от корневого test.py?»** `file test.py` выводит в том числе `literal-in tools/pipeline.py:1073`. Открыть место упоминания: pipeline вызывает `py_compile`. Сам `test.py` при исполнении вводит текст на desktop. По имени файла нельзя выбирать способ проверки.
* **«Где проверяется UI исследования символов?»** `topic ui` ведёт к launch, manifest и `tools/eval_core_symbol_ui.py`. У последнего на строках 18–20 внешний harness настраивает import roots и импортирует `app.ui`. Полный статический `file modules/developer_task_ui/app/ui.py` пропускает этого потребителя. Для UI важны и карточка поставки, и просмотр точки запуска.

```powershell
git show "${rev}:modules/reminder_service.py" | Select-Object -Skip 82 -First 18
& $python -I -S -B $nav --snapshot $rev quick CommandProcessor ActionBroker Task
& $python -I -S -B $nav --snapshot $rev session
```

`session` держит полный индекс одного снимка до EOF. Вводить по одному имени или точному пути. `find SYMBOL` показывает определения и, при единственном пути, потребителей. `brief` строит полный индекс и выдаёт компактную карточку; `quick` использует текстовый отбор перед AST и удобен для обычного объявления и нескольких известных имён. При необычной записи объявления или нулевом результате `quick` перепроверить через `find`. `edges` выдаёт полный список **статически сопоставленных** локальных import-пар с координатой одного места; `file` добавляет точные строковые упоминания. Лимит выдачи регулирует `--limit N` перед командой, остаток виден в строке `+N more`. Полный граф и весь TSV полезны для скрипта; в контекст AI выбирать только строки нужной области.

Навигатор читает имена из `git ls-tree` и байты обычных Python-файлов по blob из `git cat-file`. Для быстрых запросов используется `git grep` по тому же commit. Анализатор не делает checkout, не следует по symlink в рабочем каталоге, не импортирует анализируемые модули и не пишет кеш. Карточки задач принадлежат версии лабораторного инструмента; перед выдачей выбранной карточки он проверяет существование всех трёх её путей в заданном дереве. Доказательством остаётся исходник по пути и SHA. Статический импорт может находиться в условной ветке; строка может быть запретом, фикстурой или командой; импорт тестом не доказывает, какое поведение он покрывает.

### Сравнительная проверка

Шесть задач и ожидаемые файлы зафиксированы коммитом `8aa425d` до реализации. У каждой задачи один символ, ожидаемый файл определения и проверки; у четырёх есть конкретная требуемая локальная зависимость. У двух оставшихся вручную и проверкой подтверждены ноль разрешённых локальных импортов. Оценка выдачи — наличие трёх запрошенных указателей с учётом применимости. Для шести задач получается 16 проверяемых указателей. Это открытая выборка знакомых подсистем; измерения охватывают навигацию до кода и теста. [Задания](questions.json) · [Все повторы и результат каждой задачи](measurements.json) · [Реализация сравнения](../../../tools/navigation_lab/measure.py)

| Одинаковая серия из 6 задач | Указатели | Вывод, байт UTF-8 | Медиана серии, мс |
|---|---:|---:|---:|
| `git grep` отдельно по каждому символу, определение → импорты → проверки | 16/16 | 3 477 | 442,53 |
| Пакетный `git grep`, три вызова на всю серию | 16/16 | 3 477 | **80,42** |
| `quick`, пакетный отбор и разбор AST кандидатов | 16/16 | **1 435** | **216,31** |
| `brief`, полный индекс с нуля | 16/16 | **1 435** | 1 209,85 |

На этих задачах компактная карточка сэкономила 2 042 байта (58,7%). Обе AST-версии дали одинаковые карточки. Самый быстрый поиск при заранее известных именах — пакетный `git grep`. У `quick` есть плата за разбор и разрешение импортов, зато сразу видны пути зависимостей и координаты импортирующих проверок. Полную сборку стоит выбирать, когда нужны обратные рёбра, строковые пути или работа с несколькими последующими вопросами. На этом дереве она разобрала 515 Python-файлов и дала 1 284 различные пары «источник → локальная цель»; для динамических загрузок действуют ограничения выше.

**Метод измерения.** Windows, Python 3.12.10, Git 2.45.1.windows.1. Восемь повторов, порядок четырёх вариантов циклически менялся. `perf_counter_ns` измеряет обработку серии, в том числе создание индекса и дочерние процессы Git; запуск самого интерпретатора и работа пользователя вне таймера. Индекс строится заново в каждом повторе, файловый кеш ОС не очищался. Во всех вариантах один и тот же SHA и заголовок, одинаковый LF и UTF-8. Из вывода grep удалён повторяющийся SHA, вывод проверок сокращён до путей. Вывод `quick` проверяется побайтно через отдельный процесс CLI. Фактическая телеметрия токенов Astra/Codex, число обращений реального агента и длительность выполнения задачи человеком недоступны; экономия токенов и времени разработчика не измерена.

### Воспроизведение и границы проверки

```powershell
& $python -I -S -B tools/navigation_lab/check.py
& $python -I -S -B tools/navigation_lab/measure.py --repeats 8
& $python -I -S -B $nav --snapshot $rev audit
& $python -I -S -B tools/eval_package_boundaries.py
```

В лаборатории 10 адресных проверок: полное соответствие TSV дереву, разбор Python и координаты, повторное объявление, отдельная vendor-копия, строковая регистрация, пустой результат/лимит, маршруты, внешний UI-import, совпадение полного и быстрого ответов и реальные байты CLI. Штатный guard границ — 32/32. Эти результаты относятся к навигации и архитектурным границам. Полный runtime-pipeline, desktop-ввод, обучение и Core-эксперименты для этой задачи не запускались. Реестр содержит пути из Git. Содержимое локальных правок и личные данные находятся вне этого аудита.
