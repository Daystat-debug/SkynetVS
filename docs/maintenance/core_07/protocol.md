# Core 0.7. Выбор цели по наблюдаемому признаку

Снимок исходников — `fb30428c94b3d477dde9b5e081435a1669822aad`, прежние пять файлов. Разработчик может описать проявление, процитировать часть сообщения, спросить об условиях или об одном вызывающем участке. Исследователь выбирает место в снимке и глубину исследования. Ответ должен назвать интерпретацию вопроса, показать исходную операцию и представить достаточные для запроса доказательства либо уточнить цель. Достижение инструкции при нормальном вычислении и фактическое выполнение различаются.

До первого измерения фиксируем реализацию, затем новые вопросы и ручные рубрики отдельным коммитом. Включаем пересказы без имён и без буквальной цитаты, место, условия, вопрос о вызывающем участке, неоднозначность, отрицательные задачи и перенос на одноразовый снимок. Отдельно повторяем T05/T06/T08. Сравниваем принятый хост, лексическое ранжирование, однократный выбор цели моделью и их сочетание. Для трёх новых вариантов одинаковы каталог допустимых целей, статические инструменты, проверка и предел шести действий. Разрешена одна локальная генерация на вопрос. Сохраняем предложения модели отдельно от выданных фактов, время, количество действий, полные ответы, частичные ответы, пропуски и ошибочные выдачи. Экспериментальные вопросы не используются для настройки.
