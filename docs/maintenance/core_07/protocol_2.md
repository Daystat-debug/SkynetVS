# Второй перенос. Раздельный выбор источника и действия

Первое сравнение сохранено в `480b292`. Совместный выбор места и действия привёл к отклонению всех 17 ответов модели в соответствующем варианте. Во многих ответах модель возвращала имя функции вместо операции; также встречалось уточнение. Лексический вариант выпустил четыре ответа о посторонних местах. Сохраняем обе неудачи.

Для второй проверки изменяем представление решения. Модель может вернуть только номер места в каталоге либо ноль. Вид доказательства выбирает хост существующим распознавателем вопроса. Сильная альтернатива принимает допустимый номер напрямую. Осторожный вариант при отсутствии точной цитаты требует также первое место в лексическом ранжировании и общий отличительный термин в самой подписи. При несогласии возможно уточнение с проверяемой ссылкой. Уточнение на разрешимой задаче не получает балл за полный ответ. Ошибочные варианты уточнений учитываем отдельно.

Проверяем принятый Core 0.6, прежние лексический и гибридный варианты и оба новых способа на одинаковых заранее зафиксированных вопросах и снимках. Сохраняем все ответы и реальные обращения к модели. Синтетическая часть использует новый предметный сюжет и другие функции. Вопросы первой проверки не используются в качестве итоговой оценки этой реализации.
