# Проверка Core 0.3

Снимок для измерений — `1836acd4cf0f12900c007904e21b4a6ff0b6b5d3`. Задача разработчика — найти хотя бы один статический перенос аргумента из выражения в заданной функции к заданному именованному параметру другой функции. Назвать исходное выражение и показать все прямые вызовы и привязки параметров на этом пути. На промежуточном шаге допускается подтверждённое локальное копирование имени. Связь функций сама по себе недостаточна. Преобразования значений, динамическая диспетчеризация и выполнение программы вне утверждения.

На всех вариантах — те же пять файлов, шесть обращений к инструменту вызовов, 96 уникальных ссылок и дедлайн 25 с. Сравнить с принятым Core 0.2 на исходном вопросе и с поиском пути по функциям с последующей проверкой привязок. Сильному варианту предоставить те же проверенные символы и операции, кешировать повторные запросы. Дополнительно сравнить с перебором альтернативных путей с кешем в том же бюджете. Зачёт положительного ответа требует верного выражения в исходной функции, всех переносов в правильном порядке и привязанных Git-ссылок. Для отрицательного ответа отдельно различать обоснованное удержание и необоснованный вывод. Измерять также число поисков и задержку.

Код зафиксировать до отбора задач переноса. Отдельно оценить неизменённый проект и временные Git-снимки с развилками, изменением аргумента и неизвестными ранее идентификаторами. Для новых графов использовать воспроизводимое случайное размещение альтернатив после фиксации реализации. Не использовать ответы для настройки. В Git сохранять только открытые вопросы, эталоны, результаты и безопасные параметры контролируемых изменений.
