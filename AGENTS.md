# Навигация по SkynetVS

Из корня проекта начни поиск по обычному описанию задачи:

```powershell
.\.venv\Scripts\python.exe -I -S -B tools/navigation_lab/nav.py task "Где хранятся напоминания?"
```

Карточка указывает исходник, границу и адресную проверку. При нескольких совпадениях выбери область через `topic КЛЮЧ`. Для известного символа есть `quick ИМЯ`, для потребителей файла — `file ПУТЬ`. Навигация читает Git HEAD; для локальных правок отдельно посмотри `git diff` и `git diff --cached` по затронутым путям. Открой исходник и проверь назначение теста перед запуском.
